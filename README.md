## 🛠 Yêu cầu Cài đặt (Requirements)

Đảm bảo bạn đã cài đặt **Python 3.x** trên hệ thống.

1.  **Cài đặt Pygame:** Mở Terminal hoặc Command Prompt và chạy lệnh sau để cài đặt thư viện cần thiết:

    ```bash
    pip install pygame
    ```

---

## 🚀 Cách Chạy Game

Để khởi động game, bạn cần đảm bảo cả file code (`tictactoe.py`) và file nhạc (`Grow a Garden Soundtrack - Main Theme 2.mp3`) nằm cùng một thư mục.

1.  **Tải xuống:** Clone repository hoặc tải trực tiếp hai file cần thiết.
2.  **Chạy:** Mở Terminal/Command Prompt, điều hướng đến thư mục chứa game và thực thi lệnh:

    ```bash
    python tictactoe.py
    ```
